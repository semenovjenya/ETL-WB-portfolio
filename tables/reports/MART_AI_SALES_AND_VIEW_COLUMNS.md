# Описание столбцов: витрина AI Sales Mart и представление остатков/продаж

Документ описывает назначение каждого столбца в витрине `reports.mart_ai_sales_planning` и в представлении `reports.v_stocks_sales_daily_readable`.

---

## 1. Витрина `reports.mart_ai_sales_planning`

Материализованное представление для ML и аналитики. **Зерно:** одна строка = один `nm_id` на одну дату (`report_date`). Обновление: `REFRESH MATERIALIZED VIEW CONCURRENTLY` после загрузки исходных таблиц.

### Блок 0 — Идентификаторы и период

| Столбец       | Описание |
|---------------|----------|
| report_date   | Дата отчёта (день). |
| week_start    | Начало недели (понедельник) для этой даты. |
| nm_id         | Номенклатурный ID (артикул WB). |
| vendor_code   | Артикул поставщика. |
| brand_name    | Бренд. |
| subject_name  | Категория (предмет). |

### Блок 1 — prices и скидки

| Столбец              | Описание |
|----------------------|----------|
| price_raw            | Полочная цена до скидок (carry-forward из `wb_supplier_sales`). |
| discount_pct         | Скидка продавца, %. |
| spp_pct              | СПП (субсидия WB Клуба), %. |
| price_final          | Цена заказа = price_raw × (1 − discount%). |
| price_with_spp       | Цена с учётом СПП = price_final × (1 − spp%). |
| price_sale           | Контрольная цена из воронки (order_sum / order_count). |
| price_final_prev_week| Цена заказа неделю назад (лаг 7 дней). |
| price_change_pct     | Изменение цены к предыдущей неделе, %. |

### Блок 2 — Воронка спроса (дневные абсолюты)

| Столбец          | Описание |
|------------------|----------|
| open_count       | Просмотры карточки за день. |
| cart_count       | Добавления в корзину за день. |
| order_count_day  | orders за день. |
| order_sum_day    | Сумма заказов за день, руб. |
| buyout_count_day | Выкупы за день. |
| buyout_sum_day   | Сумма выкупов за день, руб. |
| cancel_count_day | Отмены за день. |
| wishlist_count   | Добавления в избранное за день. |

### Блок 3 — Конверсии воронки

| Столбец               | Описание |
|-----------------------|----------|
| open_to_cart_pct      | Конверсия просмотр → корзина, %. |
| cart_to_order_pct     | Конверсия корзина → заказ, %. |
| order_to_buyout_pct   | Конверсия заказ → выкуп, %. |
| is_conversion_anomaly  | Флаг невалидной конверсии: хотя бы одна из конверсий вне диапазона 0–100. |
| cancel_rate_pct      | Доля отмен от заказов за день, %. |

### Блок 4 — Эластичность спроса

| Столбец                 | Описание |
|-------------------------|----------|
| order_count_prev_week   | orders за день неделю назад. |
| order_change_pct        | Изменение заказов к предыдущей неделе, %. |
| price_elasticity_point  | Точечная эластичность (ΔQ% / ΔP%). |
| elasticity_rolling_4w   | Скользящая эластичность за 28 дней. |

### Блок 5 — stocks

| Столбец           | Описание |
|-------------------|----------|
| stock_qty         | Остаток на складах (carry-forward из `wb_supplier_stocks`). |
| stock_qty_full    | Полный остаток. |
| in_way_to_client  | В пути к клиенту. |
| in_way_from_client| В пути от клиента. |
| stock_week_avg    | Средний остаток за 7 дней. |

### Блок 6 — Оборачиваемость запасов

| Столбец               | Описание |
|-----------------------|----------|
| sales_per_day         | Выкупы за день (то же, что buyout_count_day). |
| sales_7d_sum          | Сумма выкупов за последние 7 дней. |
| sales_28d_avg_per_day | Среднее выкупов в день за 28 дней. |
| days_of_stock         | Дней запаса = остаток / sales_28d_avg_per_day. |
| stock_turnover_weekly  | Оборачиваемость за неделю = sales_7d_sum / stock_week_avg. |
| reorder_flag          | Маркер пополнения: `no_sales`, `critical`, `warning`, `ok`. |

### Блок 7 — Финансы (из `wb_report_detail_daily`)

| Столбец             | Описание |
|---------------------|----------|
| revenue_gross       | Выручка брутто. |
| revenue_net         | Выручка нетто (с учётом скидки). |
| ppvz_for_pay        | К перечислению (сумма к выплате). |
| commission_pct      | Комиссия WB, %. |
| delivery_cost       | Стоимость доставки. |
| storage_fee         | Хранение. |
| penalty             | Штрафы. |
| net_profit_per_unit | Чистая прибыль на единицу (расчётная). |

### Блок 8 — ML-фичи (исторические признаки)

| Столбец               | Описание |
|-----------------------|----------|
| sales_lag_1w          | Выкупы за 7 дней 1 неделю назад. |
| sales_lag_2w          | Выкупы за 7 дней 2 недели назад. |
| sales_lag_4w          | Выкупы за 7 дней 4 недели назад. |
| sales_rolling_4w_avg   | Скользящее среднее выкупов за 28 дней. |
| sales_rolling_4w_std   | Скользящее СКО выкупов за 28 дней. |
| product_rating        | Рейтинг товара. |
| feedback_rating       | Рейтинг отзывов. |
| open_count_lag_1w     | Просмотры карточки неделю назад. |
| open_count_rolling_7d | Сумма просмотров за 7 дней. |

### Блок 9 — Целевые переменные (постфактум для обучения ML)

| Столбец               | Описание |
|-----------------------|----------|
| target_orders_next_7d | orders за следующие 7 дней (от report_date+1 до report_date+7). |
| target_buyouts_next_7d| Выкупы за следующие 7 дней. |

### Блок A — Сезонность и акции

| Столбец               | Описание |
|-----------------------|----------|
| week_of_year          | Номер недели в году (ISO). |
| month_num             | Номер месяца (1–12). |
| is_weekend            | Признак выходного дня (суббота/воскресенье). |
| is_promo_period       | Признак: дата попадает в акцию WB (`wb_calendar_promotions`). |
| days_to_next_promo    | Дней до начала следующей акции WB. |
| yoy_orders_change_pct | Изменение заказов год к году (та же дата −364 дня), %. |

### Блок B — supplies и пополнение

| Столбец                 | Описание |
|-------------------------|----------|
| last_supply_date        | Дата последней завершённой поставки (carry-forward из `wb_supplies`). |
| days_since_last_supply  | Дней с момента последней поставки. |
| pending_supply_qty      | Количество единиц в незакрытых поставках (fact_date IS NULL). |
| avg_supply_interval_days| Средний интервал между поставками, дней. |
| reorder_qty_recommended | Рекомендуемый объём пополнения: sales_28d_avg×44 − stock_qty − pending_supply_qty (горизонт 30 дн. + страховой запас 14 дн.). |

### Блок C — marketing

| Столбец              | Описание |
|----------------------|----------|
| adv_spend_day        | Расходы на рекламу за день, руб. |
| adv_orders_day       | orders с рекламы за день. |
| has_active_campaign  | Признак: по nm_id есть активная рекламная кампания в этот день. |
| adv_cpo              | Стоимость одного рекламного заказа (adv_spend_day / adv_orders_day), руб. |
| adv_roas             | Возврат на рекламные расходы (revenue_net / adv_spend_day). |

### Блок D — Возвраты

| Столбец          | Описание |
|------------------|----------|
| return_count_day | Количество возвратов за день. |
| return_sum_day   | Сумма возвратов за день, руб. |
| net_sales_day    | Чистые продажи за день = buyout_count_day − return_count_day. |
| return_rate_30d  | Процент возвратов за 30 дней (скользящий) от выкупов, %. |

### Блок G+ — Расширенная прибыльность

| Столбец                   | Описание |
|---------------------------|----------|
| margin_pct                | Маржинальность = net_profit_per_unit / price_final × 100, %. |
| effective_commission_pct | Фактическая комиссия с учётом удержаний = (1 − ppvz_for_pay / revenue_net) × 100, %. |

## 2. Представление `reports.v_stocks_sales_daily_readable`

Удобная сводка остатков и продаж с названием товара, брендом и артикулом поставщика. **Зерно:** одна строка = один `nm_id` на одном складе на одну дату среза. В выборку попадают только склады с положительным остатком. sales подтягиваются агрегатом по `nm_id` на дату (без жёсткого джойна по складу).

| Столбец             | Описание |
|---------------------|----------|
| snapshot_date        | Дата среза остатков (день). |
| nm_id               | Номенклатурный ID (артикул WB). |
| warehouse_name      | Название склада. |
| subject             | Название категории (предмет). |
| brand               | Бренд. |
| supplier_article    | Артикул поставщика. |
| stock_quantity      | Остаток на складе (quantity). |
| stock_quantity_full | Полный остаток на складе (quantity_full). |
| sales_count         | Количество продаж (выкупов) по этому nm_id за snapshot_date (агрегат по всем складам). |
| sales_amount        | Сумма к перечислению (for_pay) по этому nm_id за snapshot_date. |
| sales_warehouses    | Список складов, с которых были продажи в этот день (через запятую). |
