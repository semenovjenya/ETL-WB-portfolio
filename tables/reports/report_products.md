# Отчёт по товарам

**Кратко для руководителя**

---

## Назначение

Сводка по каждому товару на последнюю дату: кто продаётся, по какой цене, сколько заказов и выкупов, остатки, маржа и возвраты. Одна строка — один товар (артикул WB).

---

## Готовый отчёт (файлы)

Запуск из корня проекта:

```bash
python scripts/run_report.py products
```

В папке **`tables/reports/output/`** появятся файлы:
- **report_products_YYYY-MM-DD.csv** — полная выгрузка для Excel;
- **report_products_YYYY-MM-DD.md** — таблица в Markdown (до 500 строк).

Перед первым запуском в БД должны быть созданы представления (выполнить `tables/reports/report_products.sql`).

---

## Что в отчёте

| Блок | Что смотреть |
|------|----------------|
| **Товар** | Артикул WB, артикул поставщика, бренд, категория. |
| **Цена** | Текущая цена (с учётом скидки), скидка и СПП, %. |
| **Воронка** | Просмотры, в корзину, заказы и выкупы за день; конверсии и % отмен. |
| **sales** | Выкупы за 7 дней и среднее за 28 дней. |
| **stocks** | Остаток, на сколько дней хватит, нужность пополнения, рекомендуемый объём. |
| **Финансы** | Выручка нетто, к перечислению, маржа %, прибыль на единицу. |
| **Возвраты** | Возвраты за день и % возвратов за 30 дней; чистые продажи за день. |
| **Реклама** | Расход за день, заказы с рекламы, есть ли кампания, ROAS. |
| **Рейтинг** | Рейтинг товара и отзывов. |

---

## Итог

Один срез по всем товарам: как продаётся, сколько зарабатываем, какие остатки и что с возвратами и рекламой.
